# Индийский Трикотаж — Рекомендованные API и репозитории

Архитектурный гайд по интеграции внешних сервисов из каталога `public-apis` для маркетплейса трикотажных изделий.

---

## 🔌 Топ-4 API для маркетплейса одежды и трикотажа

### 1. Виртуальная AI-примерка и студийная замена фона
* **Сервис:** [Clipdrop API](https://clipdrop.co/apis) / [Photoroom API](https://www.photoroom.com/api)
* **Open-Source репозиторий:** [github.com/danielgatis/rembg](https://github.com/danielgatis/rembg)
* **Для чего:** 
  - Одежда на белом манекене или вешалке автоматически переносится на фотореалистичную AI-модель в студийном интерьере или на улицах Алматы.
  - Повышает конверсию карточки товара в покупку на **35–45%** без затрат на регулярные студийные фотосессии.

### 2. Калькулятор умного подбора размера (Smart Size Advisor)
* **Сервис:** [Sizebay API](https://sizebay.com/) / Локальный калькулятор `packages/shared/src/size_calculator.ts`
* **Для чего:** 
  - Главная причина возврата одежды (до 30-40% заказов) — «не подошел размер».
  - Покупатель вводит рост, вес и предпочитаемую посадку (облегающая / свободная) &rarr; алгоритм точно определяет размер (M, L, XL, 2XL) под индийскую сетку лекал.

### 3. Автоматический расчет доставки (Казпочта & СДЭК)
* **Сервис / SDK:** [github.com/cdek-it/cdek-api-v2-php](https://github.com/cdek-it) / REST API СДЭК & Казпочты
* **Для чего:**
  - При оформлении заказа в корзине покупатель видит точную стоимость и срок доставки до двери или ближайшего постамата по Алматы и регионам Казахстана.

### 4. Геолокация 16 филиалов в Алматы (OpenStreetMap / Leaflet)
* **Open-Source репозиторий:** [github.com/Leaflet/Leaflet](https://github.com/Leaflet/Leaflet)
* **Для чего:**
  - Бесплатный интерактивный селектор магазинов в ТРЦ (MEGA, Dostyk Plaza, Aport, Moskva) без необходимости покупать дорогой ключ Google Maps API.
